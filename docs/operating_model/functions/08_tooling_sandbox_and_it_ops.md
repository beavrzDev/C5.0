# Business Function #7: Tooling, Sandbox & IT Ops

## What This Function Does
- **Category:** Enabling
- **Primary Owner (20 People):** DataOps & FinOps Lead
- **Primary Target KPI:** Tooling cost per person $< \$600/\text{month}$; 99.9% internal sandbox uptime

---

## Goals
1. **Developer Workstations & Tooling:** Provision standard development environments (workstations, Git repositories, IDEs, transformation platforms).
2. **Multi-Cloud Sandboxes:** Manage dedicated AWS, Azure, and GCP accounts funded through partner tier credits for Databricks R&D and customer demos.
3. **Observability & CI/CD:** Maintain internal CI/CD runner pools, automated code linters, and automated data testing suites.
4. **Access Control & Credential Management:** Centralized secrets management with strict least-privilege policies.

---

## How This Works
- **Approved Tooling Catalog:** Approved software stack for engineering, operations, and client collaboration.
- **Cloud Sandbox Governance:** Auto-shutdown scripts for idle clusters to eliminate unnecessary compute spend.
- **IT Onboarding & Offboarding:** Rapid 1-day developer provisioning via automated Mobile Device Management (MDM).
