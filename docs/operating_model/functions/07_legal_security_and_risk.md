# Business Function #7: Legal, Security & Risk Governance

## What This Function Does
- **Category:** Enabling
- **Primary Owner (20 People):** Principal Data Architects (Supported by External Legal Counsel)
- **Primary Target KPI:** Zero compliance violations; clean annual SOC 2 Type II audit

---

## Goals
1. **Outcome-based Contracts:** MSA and SOW templates designed for Definition of Done (DoD) deliverables and sprint-based scoping.
2. **Cloud Cost & Liability Protection:** Explicit contractual caps that protect the firm from client cloud compute overruns during load tests or pipeline runs.
3. **Data Security & Privacy:** Strict PII masking, zero client data retention policy (no client data on consultant machines), and HIPAA/GDPR adherence.
4. **IP Rights & Open-Source:** Retaining firm ownership over reusable macros, IaC modules, and general frameworks while assigning client-specific schema/models to the client.

---

## How This Works
- **Standard SOW Clause Structure:** Acceptance criteria, change request thresholds, cloud compute liability limits.
- **Data Security Controls:** Ephemeral cloud workstations, role-based access control (RBAC), and multi-factor authentication enforcement.
- **Vendor & Subcontractor Agreements:** IP assignment agreements and confidentiality covenants for all 1099 talent.
